# Public-release checklist

- [ ] Confirm `teesta_sediment_yield_gee.js` is the exact version used for the manuscript.
- [ ] Add all author names and affiliations to `README.md`.
- [ ] Make the required Earth Engine boundary asset publicly readable, or document a public replacement.
- [ ] Verify the GEE snapshot link opens correctly.
- [ ] Add an appropriate software license.
- [ ] Create a GitHub release (recommended tag: `v1.0.0`).
- [ ] Archive that release in Zenodo and obtain a DOI.
- [ ] Add the Zenodo DOI to the README and manuscript Code Availability statement.
